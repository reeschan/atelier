Template Studiopbi-orchestration-jev の振り分けテンプレート (routing.json) を組み立てる

一覧の日付 — 性能と価格は仮の値
Step 1

使うモデルを選ぶ

契約している実行先だけを残してください。チップ 1 つが route の 1 段 (実行先・モデル・effort) になります。

Tuning

段ごとの性能の下限

select_model.py が決める段 (haiku / sonnet / opus) ごとに、これより低いモデルは route に入れません。

Step 2

テンプレート案から選ぶ

同じモデルの組み合わせから、性能・コスパ・バランスの 3 案を作りました。目安の費用は 1 PBI = 入力 30 万・出力 3 万トークンの API 換算です。

Step 3

routing.json を書き出す

対象リポジトリの docs/pbi/routing.json に置くと、prepare.py (select_model.py --all) がこの表で route を出します。


      
python skills/pbi-orchestration-jev/select_model.py --all docs/pbi

    

  


  
モデル一覧は studio/update_catalog.py が OpenRouter (価格・新モデル) と Artificial Analysis (性能指標) から作ります。
