Template Studiopbi-orchestration-jev の振り分けテンプレート (routing.json) を組み立てる

一覧の日付 — 性能と価格は仮の値
Step 1

使うモデルを選ぶ

契約している実行先だけを残してください。チップ 1 つが「試す順番」の 1 つ (実行先・モデル・effort) になります。

Tuning

作業の重さごとの性能の下限

PBI は 1 件ずつ、Jev の判定と変更の大きさから「軽い作業」「ふつうの作業」「設計が要る作業」のどれかに分けられます。それぞれ、これより性能の低いモデルは案に入れません。

Step 2

テンプレート案から選ぶ

同じモデルの組み合わせから、性能・コスパ・バランスの 3 案を作りました。目安の費用は 1 PBI = 入力 30 万・出力 3 万トークンの API 換算です。

Step 3

試す順番を調整する

選んだ案をもとに、作業の重さごとに上から順に試します。ドラッグか ↑ ↓ で並べ替え、チェックを外したものは使いません。使えなかったときの最後の受け皿は、Claude Code のモデルから選びます。

調整済み
Step 4

routing.json を書き出す

対象リポジトリの docs/pbi/routing.json に置くと、prepare.py がこの順番で実行先を試します。


      
python skills/pbi-orchestration-jev/select_model.py --all docs/pbi

    

  


  
モデル一覧は studio/update_catalog.py が OpenRouter (価格・新モデル) と Artificial Analysis (性能指標) から作ります。
