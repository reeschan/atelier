# PBI-011: agent_stats.py --ctx をサブエージェントと headless のセッションでも測れるように

- Model: (route.json)
- Depends on: none

## Goal
設計者は Agent のサブエージェントか claude -p のセッションで動くので、今の --ctx (呼び出し側のセッションを測る) では自分の文脈を測れない。description と session id で測れるようにする。

## Targets
- `skills/atelier/agent_stats.py`: `--ctx` を `--session <id>` と一緒に使えるようにする (今は相互排他)。`--ctx --agent <description の先頭>` を足す: `common.project_dir_for(Path.cwd())` の下の `**/subagents/agent-*.meta.json` を再帰で探し (入れ子の記録も拾う)、description がその文字列で始まるもののうち、対になる `agent-*.jsonl` が最後に更新されたものを測る。見つからなければ `context=unknown` を出して終了コード 3。出力の形は今の `context=<n> peak=<n> requests=<n>` のまま。

## Do not touch
- `skills/atelier/record_run.py`・`skills/atelier/common.py`

## Acceptance criteria
1. 1 の終了コードが 0。
2. 2 の `--help` に `--agent` が出る。
3. 3 が `context=unknown` を出し、終了コード 3。
4. 4 が何も出さず終了コード 0。

## Verify commands
1. `python -m py_compile skills/atelier/agent_stats.py`
2. `python skills/atelier/agent_stats.py --help`
3. `cd skills/atelier && python agent_stats.py --ctx --agent "NO-SUCH-AGENT-xyz"; test $? -eq 3 && echo exit3`
4. `python docs/pbi/tools/unchanged.py check PBI-11`
