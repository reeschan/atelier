# PBI-008: 付録 handoff・kiln・verify を出番とレビュー担当に合わせる

- Model: (route.json)
- Depends on: PBI-006

## Goal
引き継ぎと Kiln を、ユーザーの /clear ではなく出番の handoff で済ませる形にし、PBI ごとの検証をレビュー担当に移す。

## Targets
- `skills/atelier/appendix/handoff.md`: 先頭に「進行役のもとでは、引き継ぎは status `handoff` の出番の結果。進行役がすぐ新しい設計者を起こすので、ユーザーに /clear と resume を頼まない。以下の Hand off と Resume は inline (後ろ盾) のときだけ」。Measure は `Context probe:` の行のコマンドを使う。
- `skills/atelier/appendix/kiln.md`: Designer の節の Act を、進行役のもとでは suggest・compact・handoff のどれも状態の板を書いて handoff で終える (`/compact` は使わない) に。Measure は依頼文の `Context probe:` の行。表の Handoff の行の意味を「出番を handoff で終える (inline では /clear と resume)」に。
- `skills/atelier/appendix/verify.md`: Triage は設計者のまま。`## Check` をレビュー担当 (`prompts/pbi-review.md`) に移し、設計者は `role_results.py bundle` の表で照合する節 `## Reconcile` を足す (照合が要る行だけ review.json を開く、verify の合否は `docs/pbi/verify/<報告名>.json`、指摘は自分でファイルを開いて確かめる)。`## Decide and record` はそのまま。
