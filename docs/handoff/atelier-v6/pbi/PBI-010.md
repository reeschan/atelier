# PBI-010: 付録 adapters・lint・optional の問いを出番の question に

- Model: (route.json)
- Depends on: PBI-006

## Goal
承認・送信の許可・ask-user の問いを、設計者がユーザーに直接聞くのではなく question の結果で返す形にそろえ、SKILL.md を指していた所を designer.md に直す。

## Targets
- `skills/atelier/appendix/adapters.md`: `## Confirm` の 3・4 を「question kind `approve` (`check: design-record`、path `docs/pbi/notes/approve.md`) で出番を終える。返信の照合 (`check-reply`) は呼び出し側の `conductor.py answer` が行い、通った返信だけが `Answer:` で来る」に。`SKILL.md` を指す 2 か所を `designer.md` に。
- `skills/atelier/appendix/lint.md`: The send approval の 3 を「question kind `send-approval` で出番を終える (inline では AskUserQuestion)」に。`SKILL.md` の 5 番目の止まる場所を `designer.md` に。
- `skills/atelier/appendix/optional.md`: `ask-user` の問いを question kind `decision` に (inline では AskUserQuestion)。`SKILL.md` を `designer.md` に。
