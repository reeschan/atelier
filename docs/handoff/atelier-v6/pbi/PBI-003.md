## Notes
- 仕様: `docs/specs/atelier-v6.md` (このリポジトリの v6 の仕様)。用語は `skills/atelier/CONTEXT.md`。
- 指示文 (.md) は英語で書く。既存の付録の文体 (短い命令形、1 行 1 規則) に合わせる。スクリプトの docstring とコメントは日本語 (既存のスクリプトに合わせる)。
- テストは最後にまとめる (tests-at-end)。`skills/atelier/test_*.py` を作らない・変えない。
- 起動: 実行ファイルは環境変数 `ATELIER_DESIGNER_CMD` (JSON の文字列の配列) があればそれ、無ければ `claude_run.claude_command()`。その後ろに `-p --output-format json --agent atelier-designer --model <m> [--effort <e>] --permission-mode <roles.designer.permission_mode> --permission-prompts none --session-id <seq の uuid>`。依頼文は標準入力で「<依頼文のパス> を読み、その指示どおりに作業してください。」と依頼文の本文。環境は `claude_run.build_env()` (API キーなどを外す)。cwd は今のディレクトリ (作業ルート)。
- 出力: 標準出力を `<dir>/conductor/episodes/<seq>-<出番>.json`、標準エラーを `.err` に書く。JSON が読めれば `session_id` と `total_cost_usd` を history のその seq の行に `session_id`・`cost_usd` として足す。
- 1 回の起動のあとは `done` と同じ処理をする。ready なら次の `next` と起動を続ける。question → 10、finished → 0、failed (2 回目の失敗は launch-failure の問いになるので 10) で止める。`--max-episodes N` は N 回起動したら ready のまま 0 で止める。
- `status` に費用の合計 (`cost: $<合計の小数 2 桁>`) を出す。
- run は launch が headless でなくても動いてよい (呼び出し側が選んだ)。
