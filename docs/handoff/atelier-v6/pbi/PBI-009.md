# PBI-009: 付録 tests-at-end・review をテスト担当とレビュー担当に合わせる

- Model: (route.json)
- Depends on: PBI-006

## Goal
波の終わりのテスト・テストの工程の下調べ・最後の通しをテスト担当に任せ、最終レビューをレビュー担当で回して、設計者は結果を照合するだけにする。

## Targets
- `skills/atelier/appendix/tests-at-end.md`: Start の fields に任意の `skill` (テスト担当が呼ぶテストのスキル。無ければ `verify.py --deferred`) を足す。`## End of a wave` の 1 (deferred の実行) と仕分けの案をテスト担当 (`prompts/tester.md`、kind `wave`) に、`## Test stage` の 2 (Survey) を kind `survey`、5 (Close) の通しを kind `final` に。設計者は test-result の JSON を照合して決める (cause は案)。
- `skills/atelier/appendix/review.md`: `## Run a review skill` の起動を `atelier-reviewer` に (今の `prompts/final-review.md`)。`## Findings` の前に「全部の結果がそろってから照合する」を 1 行。
