# PBI-007: SKILL.md を呼び出し側の手順に、CONTEXT.md に新しい役割

- Model: (route.json)
- Depends on: PBI-006

## Goal
スキルを呼んだセッションは、ユーザーと話して進行役を回すだけにする。用語集に新しい役割と出番を足す。

## Targets
- `skills/atelier/SKILL.md`: frontmatter はそのまま (description に「the caller only talks with the user; Atelier's designer does the work」を足してよい)。本文: You are the caller (設計・実装・レビューをしない、PBI・差分を読まない)、Start (目的を 2〜3 行で言い直す → `conductor.py start --goal-file`、Claude Code なら launch agent、そうでなければ headless)、The loop (`next` → Agent ツールで `atelier-designer` を起動 (subagent_type・model・description・依頼文は「<prompt のパス> を読み、従う」) → `done` → 出力の行をそのままユーザーに 1〜2 行で)、headless (`conductor.py run` を裏で、終わったら出力を読む)、Questions (question の kind ごとに: approve は `approve.md` をそのまま見せ (confirm の skill があれば skill で)、返信をファイルに保存して `answer --reply`、ほかは答えを `answer --text`)、Resume (`status` と `next`。/clear は要らない)、Fallback inline (`designer.md` に自分で従う)、Arguments (`setup` などは `appendix/setup.md`)。
- `skills/atelier/CONTEXT.md`: Roles に caller (呼び出し側)、conductor (進行役)、reviewer (レビュー担当)、tester (テスト担当) を足し、orchestrator (設計者) の説明を「Atelier が持ち、出番ごとに新しく起動される設計者。inline のときは呼び出し側のセッション」に直す。Workflow に episode (出番) と episode result (出番の結果) を足す。

## Do not touch
- `skills/atelier/designer.md`・`skills/atelier/appendix/episodes.md`

## Acceptance criteria
1. 1 が `OK` で終わり、終了コード 0 (SKILL.md の 120 行・5,000 トークンの上限と参照)。
2. 2 が 1 以上を出す。
3. 3 が 1 以上を出す。
4. 4 が何も出さず終了コード 0。
