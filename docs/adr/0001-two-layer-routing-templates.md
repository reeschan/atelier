# 0001 振り分けテンプレートと優先テンプレートを 2 層で共存させる

## 状態

採用済み。

## 背景

振り分けテンプレート (いつもの振り分け) は、段ごとの route と最後に受ける agent を定める。優先テンプレート (期限付きの上書き) は、期間を区切って一部の段の route を差し替えるために、別の仕組みとして生まれた。

2 つを同時に使うと、同じ PBI にどちらを先に当てるか、最後にどの agent が受けるかが決まらない。

## 決定

2 つを 2 層で共存させる。優先テンプレートを先に当て、その段の route のあとに振り分けテンプレートのその段の agent を最後の受け皿として置く。

優先テンプレートを当てない段は、振り分けテンプレートの route をそのまま使う。sensitive な PBI には優先テンプレートを当てない。

## 結果

解決順を 1 か所 (select_model.py) に置き、ほかのコマンドは決まった route だけを受け取る。

優先テンプレートを足しても振り分けテンプレートの解決は変わらず、優先順の規則も 2 か所に分かれない。
