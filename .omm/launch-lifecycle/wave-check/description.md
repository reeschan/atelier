wave の検査。building で作れる PBI が尽きると `wave_built` で checking に移り、check の行動が 1 件出る。drive は `_run_check` でコマンドを全部流して (落ちても最後まで) 結果を書き、`_cmd_done` → `_handle_check_done` で当てる。通れば built の PBI を passed にし、残りがあれば `wave_passed_next` で building、無ければ `all_pbis_passed` で reviewing。落ちたら、コマンドの終了コードから落ちた PBI を割り出し、持ち越し CO-n にして修正の PBI を次の wave の頭に入れる (`carried_next`)。最後の wave なら `carried_last` で reviewing。同じ持ち越しの修正の PBI が 2 回落ちたら asking_rebuild。修正の段 (fixing) の検査は、全グループが終わったあとに 1 回 (fixcheck)。
