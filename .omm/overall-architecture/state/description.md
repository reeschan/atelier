run.json の読み書きと PBI の状態の扱い。`ready_wave_pbis` は依存が通った（または免除された）未完の PBI を返し、`buildable_pbis` はそのうち作るもの（未着手・作っている途中・落ちた）を計画の順に返す。PBI の status は pending → building → built → passed / failed / carried / held。修正の段のグループは `fix_groups_done` で終わったものを覚え、`fix_groups_left` が残りを返す。持ち越し（CO-n）と修正の PBI（CO-n-FIX）の作成と精算もここにある。起動の番号は `next_launch_id` が `counters.launch_seq` から振る（一斉起動は `batch-NNNN`）。
