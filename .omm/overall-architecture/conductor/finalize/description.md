`_finalize_completion`（1 本の起動と check）。結果を検証し、起動なら使用量を記録し（まだなら）、番号を `completed_launches` に足し、check なら `_handle_check_done`、起動なら作業者の CRLF を戻して（`_restore_lf`）`_handle_launch_done` で状態を進め、`_advance_and_save` で次の行動を作る。building の起動が終わると PBI を built にし、まだ作る PBI があれば `worker_returned`、無ければ `wave_built` で checking に進む。fixing の起動が終わると、そのグループを `fix_groups_done` に足し、残りがあれば次のグループ、無ければ subphase を check にする。一斉起動の受け入れも、起動ごとに `_handle_launch_done` を通る。
