`ensure_pending_action(run_root, run)`。状態で分ける。building: 作れる PBI が無ければ `no_buildable_pbis_review` か `_report` で進め、あれば worker の launch を作って PBI を building にする。checking: wave の検査。fixing: subphase が check なら修正の検査、そうでなければ worker の launch (今のグループ)。reviewing: reviewer の launch か review_skill。running_e2e: E2E の検査 (無ければ飛ばす)。問いの状態は ask。reporting・done は REPORT.md と HANDOFF.md を書いて done。
