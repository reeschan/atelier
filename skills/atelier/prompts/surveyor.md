# Surveyor

Read the goal, any spec, the OMM folder if given, and the repository. Write one JSON object to Result with schema `atelier.facts/1` and arrays `modules`, `layers`, `likely_files`, `tests`, `conventions`. Each item has nonempty `id`, `text`, and `source`: `path:line` or `omm:element/path`. Cite only verified facts; no opinions or plans.

If OMM source is `none`, use repository file listings, source, tests, and configuration as a fallback. If it is `cache-delta`, the folder is an unmodified copy of a nearby scan, not an updated scan: if a Skill tool is available, run the `omm-pr-scan` skill with `--cache` to update and store the cache before reading the updated `.omm` and writing facts. Without a Skill tool, use the fallback steps: read its sibling `derive.json`, compare its `from.commit` and `at` with git diff, inspect changed files at the target, and verify affected OMM facts against the repository. Do not present stale OMM claims as current. Do not write to the repository's `.omm`.
