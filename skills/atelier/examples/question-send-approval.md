## 結論 {span=2}
```callout warn 外のモデルにファイルの中身を送ります
コードの点検のために、変えた 3 つのファイルの中身を、外の点検サービスのモデルへ送ろうとして止まっています。費用の見込みは約 $0.04 です。送れば見直しのあとの点検の結果が得られて run が進みます。送らなければ、ファイルは手元から出さず、手元の点検 (関数の長さや入れ子の深さ) だけを走らせて進みます。
```

## 今の流れ
```flow
(作業が終わる) -> 見直しが通る
見直しが通る -> *点検にかける前で止まった: ファイルの中身を外へ送る確認が要る
点検にかける前で止まった -> (あなたの返事を待つ)
```

## 答えたあとの流れ
```flow
(あなたの返事を待つ) -> {送るか}
{送るか} -> 外のモデルがファイルの中身を読む: 送る
外のモデルがファイルの中身を読む -> 指摘の一覧が戻る
指摘の一覧が戻る -> 指摘を直して run が進む
{送るか} -> 手元の点検だけを走らせる: 手元の点検だけ
手元の点検だけを走らせる -> 手元の点検の結果で run が進む
```

## 決めること {span=2}
```ask
変えた 3 つのファイルの中身を、外の点検サービスのモデルへ送りますか
* 送る | 外のモデルが中身を読み、指摘の一覧が戻る。指摘があれば直してから進むので、少し時間が延びる。費用は約 $0.04 かかる
- 手元の点検だけ (AST だけ) | ファイルは手元から出ない。外のモデルの点検は無く、手元の点検 (関数の長さや入れ子の深さ) だけで進む。費用はかからない
```

## 判断の材料 {span=2}
送ると決めた場合の試し送りの数です。

| 送り先 | ファイル数 | トークン | 費用の見込み |
|---|---|---|---|
| 外の点検サービス | 3 | 約 12,000 | 約 $0.04 |

送るのは次の 3 つのファイルの中身だけです。承認の記録や返事は送りません。

| ファイル | 変わったこと |
|---|---|
| `src/view/Header.tsx` | 見出しの文言を直した |
| `src/view/Header.test.tsx` | 直した見出しの試験を足した |
| `src/theme/index.ts` | 見出しの色を 1 つ足した |
